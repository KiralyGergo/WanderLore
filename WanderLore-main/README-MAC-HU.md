# WanderLore – macOS indítás

1. Csomagold ki a ZIP-et.
2. Terminálban lépj a `WanderLore-main` mappába.
3. Futtasd:

```bash
dotnet restore
dotnet run
```

A főmenüben ENTER indítja a játékot, ESC visszalép a menübe, a menüben ESC kilép.
Mozgás: WASD vagy nyílbillentyűk; SPACE gyorsít.

A pálya 100 × 100 mezős mátrixból épül fel. A fűcsempék ismétlődnek, az erdős foltok véletlenszerűen generálódnak. A kamera követi a sünt.
